# אודיט QA

שלב 2: כל הממצאים תוקנו על הענף הזה. הטסטים ב־`tests/test_qa_audit.py` (בלי `xfail`).

## מה תקין (נשאר)

| נושא | מה קורה |
|---|---|
| תזכורת לאירוע בלי שעה | בסיס `REMINDER_DEFAULT_TIME` (ברירת מחדל **09:00** שעון ירושלים). offset 12 שעות → 21:00 בערב שלפני. |
| DST | 09:00 נשאר מקומי: חורף UTC+2, קיץ UTC+3. |
| רב־יומי | התזכורת לפי **תחילת** האירוע. |
| חזרות | 29 בפברואר→28, יום 31 חודשי→סוף החודש, ל׳ חשוון/כסלו קצר→כ״ט, אדר פשוט→אדר ב׳ במעוברת. |
| תזכורת חוזרת | שליחה per-occurrence + per-chat ב־`reminder_sends`. |
| רשת משמרות | שמירה כפולה אידמפוטנטית; טקסט חופשי לא נמחק; תא אסור נדחה; חריג ידני מותר. |
| מיגרציה | גרסה **3**, `BEGIN IMMEDIATE`, אידמפוטנטית על DB טרי וישן. |

## לא באג (מכוון)

- משמרת ידנית **עוקפת** `shift_allowed` — רק הרשת דוחה תא אסור.
- מחיקת אדם **משאירה** את שורות המשמרת.
- תזכורת בלי מזהה צ'אט: דפדפן כן, טלגרם לא.
- Web Push עדיין לא קיים (`push.supported: false`).
- אין הרשאות — עותק ביתי אחד.
