# אודיט QA — שלב 1 (בלי שינוי התנהגות)

בדיקה מקצה לקצה אחרי המיזוגים האחרונים. הטסטים ב־`tests/test_qa_audit.py`. באג מאושר מסומן `xfail`.

## מה תקין (אושר בקוד ובטסטים)

| נושא | מה קורה |
|---|---|
| תזכורת לאירוע בלי שעה | בסיס `REMINDER_DEFAULT_TIME` (ברירת מחדל **09:00** שעון ירושלים). offset 12 שעות → 21:00 בערב שלפני. סביר. |
| DST | 09:00 נשאר מקומי: חורף UTC+2, קיץ UTC+3. |
| רב־יומי | התזכורת לפי **תחילת** האירוע, לא הסוף. |
| חזרות | 29 בפברואר→28, יום 31 חודשי→סוף החודש, ל׳ חשוון/כסלו קצר→כ״ט, אדר פשוט→אדר ב׳ במעוברת. |
| תזכורת חוזרת | שליחה per-occurrence ב־`reminder_sends`. מופע שנמחק לא נשלח. |
| רשת משמרות | שמירה כפולה אידמפוטנטית; טקסט חופשי («יום מחלה») לא נמחק; תא אסור נדחה; חריג ידני מותר. |
| צ'אט טלגרם | פורמט `-?\d{1,20}` נאכף. `/start` בורח HTML. הודעת תזכורת **plain text** (בלי `parse_mode`). |
| לוח / אג'נדה | כותרת משתמש עוברת `escapeHtml`. |
| מיגרציה | גרסה 2, `BEGIN IMMEDIATE`, אידמפוטנטית על DB טרי וישן (גם במקביל). |
| מחיקת אירוע | מוחק תזכורות + `reminder_sends` + חריגות. עריכה בלי מפתח `reminders` משאירה אותן. |

## לא באג (מכוון)

- משמרת ידנית **עוקפת** `shift_allowed` — רק הרשת דוחה תא אסור.
- מחיקת אדם **משאירה** את שורות המשמרת (נבדק ב־`test_shifts`).
- תזכורת בלי מזהה צ'אט: דפדפן כן, טלגרם לא.
- Web Push עדיין לא קיים (`push.supported: false`).
- אין הרשאות — עותק ביתי אחד.
